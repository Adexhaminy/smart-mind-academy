SMART MIND ACADEMY — HTML, CSS & JAVASCRIPT VERSION

Files:
- index.html: website structure
- styles.css: all styling and responsive layout
- app.js: interactions, coding playground, quiz, and demo progress
- README.txt: setup instructions

How to run:
1. Keep all three code files in the same folder.
2. Double-click index.html to open it in a modern browser.
3. For best results while editing, use a code editor such as Visual Studio Code and refresh the browser after saving.

The coding playground previews student HTML inside a sandboxed iframe.
Student accounts, cloud-synced progress, a real AI tutor, and online hosting are not included in this front-end prototype.
